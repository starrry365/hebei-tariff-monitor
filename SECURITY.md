# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private vulnerability reporting instead:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue and, if possible, include steps to reproduce.

This repository is a personal project. Reports are reviewed on a best-effort
basis, and acknowledgement may take several days.

## Scope

In scope: the data-collection scripts, the workflow definitions, and the
published GitHub Pages site.

Out of scope: the upstream carriers' own services, and any data that this
project merely aggregates from public sources.
