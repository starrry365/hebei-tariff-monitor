# 河北电信资费采集深度核查报告（2026-10-03）

**结论：✅ 采集完整、数据与上游实时完全一致（同日双采零差异）。**

## 背景

电信是四网中唯一不能用脚本直连的：`tariffSection.do` 被瑞数类 JS 挑战 WAF 保护
（纯 HTTP 必 412，`navigator.webdriver=true` 的自动化浏览器被 400 硬拒）。
唯一实测通路 = **真实 Chrome + 远程调试口**（不带 `--enable-automation`），
页面内用 CryptoJS 造 AES 加包体调 API（密钥 `telecom_wap_2018`，已破解自证）。

本轮核查在本机复现了完整采集链路，与今日 CI 快照独立对账。

## 审计中的方法论说明

第一版字段比对报出 12 个字段 779 条「差异」，排查后是**假差异**：快照存的是适配器
归一化后的字段（如 `onlineDay: 20201107`），实时原始报文是未归一格式
（`2020-11-07 00:00:00`）。修正方法：实时原始数据先过 `ct_monitor.fetch_all()`
（与正式采集同一转换）再做同格式对账——归一化后 21 字段全部零差异。
