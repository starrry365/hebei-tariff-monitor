# 运营商官方标志（左上角品牌位用）

页面左上角品牌位显示**当前所选运营商**的官方标志。本目录是这些标志的来源留档，
模板里内联的是其中的 `emblem-*.svg|png`。

|---|---|
| `china-mobile.svg` | 中国移动横版 logo 原图（标志 + 文字） |
| `china-unicom.svg` | 中国联通横版 logo 原图（2023 版式，内嵌位图，体积较大） |
| `_alt-china-unicom-legacy.svg` | 联通旧版横版 logo（矢量，备选来源） |

| `emblem-china-unicom.png` | **入库内联**：联通标志（中国结），144×144 |
| `emblem-china-telecom.svg` | **入库内联**：电信标志（天翼 / e 标），已裁掉文字 |
| `emblem-china-broadband.png` | **入库内联**：广电标志（球标），144×144 |

来源均为中文维基百科条目内嵌的官方 logo 文件（`upload.wikimedia.org`），
条目：中国移动 / 中国联通 / 中国电信 / 中国广电。原图即上表的横版 logo。

## 处理方式

1. **裁出标志**：横版 logo 是「标志 + 中英文名称」，整条缩到 36px 看不出是什么。
   用「列扫描找标志与文字之间的空白分界」定位标志，按真实边界框裁切，
   再以最长边补成正方形（联通的中国结比文字还宽，按高度裁会切掉两侧）。
2. **尺寸**：位图统一缩到 144×144（页面显示 26px，覆盖 3× 以上像素密度）；
   矢量保留原始 viewBox，去掉 width/height 交给 CSS。
3. **清洗**：内联前去掉 XML 声明 / 注释 / `<metadata>` / `sodipodi:namedview`，
   只留渲染必需的节点。

## ⚠️ 商标说明

上述标志是各运营商的**注册商标**，此处为**指明数据来源**的指示性使用
（nominative use）：页面展示的是对应运营商的资费数据，用其标志标识「这一屏是
谁的资费」。**不表示任何官方背书、合作或授权关系**，也未对标志做任何改动
（仅裁掉文字部分做等比缩放）。
