# 河北移动 IPTV 实测源 · 96 台

河北移动宽带（邢台，600M）实机逐条实测的 IPTV 直播 + 回看方案。所有速度均为 2026-10-05 深测（3 轮 × 6 秒/台）中位值，全部经 PotPlayer 实机播放验证。

## 快速使用

### 看直播

把 [`河北移动IPTV-终版96台.m3u`](河北移动IPTV-终版96台.m3u) 导入任意播放器（PotPlayer / APTV / TiviMate 等）：

- 本机：双击 m3u 文件即可
- 其他设备：订阅 raw 地址
  ```
  https://raw.githubusercontent.com/starrry365/hebei-tariff-monitor/main/iptv/河北移动IPTV-终版96台.m3u
  ```
  （国内网络访问 raw 建议挂代理，或加 `https://ghproxy.net/` 前缀）

**注意：仅河北移动宽带内网可用**（OTT 源走移动内网 CDN，运营商外/异地收不到）。

### 看回放（时移）

需要 Python 3，在本目录执行：

```bash
python catchup.py                    # 列出 70 个可回看频道及归档深度
python catchup.py CCTV-1 30          # 回看 CCTV-1 30 分钟前，默认看 10 分钟
python catchup.py CCTV-1 30 20       # 30 分钟前开始，回看 20 分钟
python catchup.py 湖南卫视 12:00 30  # 回看今天 12:00 起的 30 分钟
python catchup.py CCTV-5 -30 -list   # 只生成文件不自动打开播放器
```

生成的 `_catchup.m3u8` 会被 PotPlayer（默认路径 `D:\PotPlayer`）自动打开；其他播放器手动打开该文件即可。播放器路径可用环境变量 `POTPLAYER` 覆盖。

### 回看原理（为什么有的台回看不了）

- 河北移动 OTT 源有两棵目录树：`030000001001` **有 7 天归档**，`030000001000` 彻底无归档
- 回看分片 URL 必须锚定到**流的 10 秒栅格**（以直播播放列表的 `PROGRAM-DATE-TIME` 推算），用挂钟时间直接拼时间戳会 404——`catchup.py` 已处理，并自动校验归档深度、兼容两种分片命名

## 实测结论摘要（详见 [APTV源探测实测报告-20261004.md](APTV源探测实测报告-20261004.md)）

1. APTV 页面的"河北移动专用源"已死（404）；公开大源里筛出 80 台可用，itvlist 通过率最高
2. **单轮测速不可信**：并发会把 OTT 源压垮测出假慢，限流 + 多轮取中位才准；同一 URL 白天/晚高峰差 3~10 倍
3. 全网搜的 bztv/百视通/黑龙江移动/河北广电官方源全部失效；电信/联通源是组播 rtp，普通宽带收不到
4. OTT 服务器有错标（如 `xuandongkaton` 实播 CCTV-14），频道真实性以实拍截图为准
