# 中国移动「资费专区」· 全量逆向与数据获取（河北）

> 抓包 2026-09-20 16:58 · 分析 2026-09-20 17:20 · 省份：河北（`province=311`）
> 结论：**能脱离 APP 全量拉取（无 token / 无签名）；但它是只读的备案公示目录，没有可薅的活动。**

## 一、这是什么

中国移动 APP 内点开的「资费专区」，是一个 H5 页：

```
GET https://h.app.coc.10086.cn/cmcc-app/uni-pages/tariffZonePers.html
      ?pageId=1834149966764851200&channelId=P00000132579&yx=1390478183
```

运行在 APP 内 WebView（UA 尾 `leadeon/12.5.4/CMCCIT`、`x-requested-with: com.greenpoint.android.mc10086.activity`）。

底层走的是 **`nrapigate` 网关** —— 与 09-16 逆向过的「动感地带专区」**同一套网关**，
只是业务分组不同（那边是 `nrzone`，这里是 `nrtariff`）。

页面本质：**把河北移动报备的资费条目按分类列出来供用户浏览/查询**（每条都带报备编号 `reportNo`）。

## 二、接口面

| 方法 | 路径（前缀 `/website/nrapigate/`） | 作用 |
|---|---|---|
| POST | `nrtariff/new/Tariff/getType2List` | **分类树** → 返回 18 个 `(tariffAttr,type1,type2)` 组合 |
| POST | `nrtariff/new/Tariff/getTariffSeriesNameList` | 某分类下的**资费系列名**列表 |
| POST | `nrtariff/new/Tariff/getTariffListInfo` | **资费明细**（核心，分页；一次返回该分类下全部系列） |
| POST | `nrtariff/new/Tariff/getStandardlist` | 标准资费（河北返回空 `[{}]`） |
| POST | `nrtariff/new/tariffZone/getEvaluationRule` | 评价规则（返回 `data:null`） |
| POST | `nrtariff/new/Tariff/getWatermarkSwitchConfig` / `getClientVisibilitySwitchConfig` | 水印/可见性开关 |
| POST | `nrtariff/new/popupWindows/getPopupFrequencyInfo` / `getPopupSortInfo` | 弹窗控制 |
| POST | `nrlzone/.../contact/list`、`nrtariff/new/tariff/personal/contact/list` | 触点配置 |
| POST | `nrauth/auth/encryt/userAuth` | APP 内换登录态（**直连不需要**） |

**分类字典**（从主 bundle `index.js` 的 `ZFLXMAP` 还原）：

`type2`: 1 套餐 · 2 加装包 · 3 营销活动 · 4 港澳台/国际资费 · 5 标准资费 · 6 国际及港澳台标准资费 · 7 其他
`tariffAttr`（=JS 里的 `rangeType`）: 首页第一项是「全网资费」

## 三、🔴 关键结论：不需要任何凭据

**明文请求体 + 不带 `x-token` + 不带 `x-sign`，直接返回数据。** 实测（curl 裸发）：

```
POST /website/nrapigate/nrtariff/new/Tariff/getTariffSeriesNameList
body: {"province":"311","isPublic":"1","tariffAttr":"1","type1":"1","type2":"1"}
→ {"body":"<AES 密文>"}
```

只需带对基础头（`User-Agent` 含 `leadeon/…`、`Origin`、`Referer`、`x-qen`、`x-app-version`、`channelid`）。
响应恒为 `{"body":"<密文>"}`，用 09-16 已还原的密钥本地解密：

```
AES-256-CBC / Pkcs7，key = <32 字节 ASCII>，iv = <16 字节 ASCII>
```

> 🔴 **密钥本体不入本仓库**（本仓库为公开仓库）。取值方式见 `cloud/tariff/mz_crypto.py`：
> 环境变量 `NRAPIGATE_KEY` / `NRAPIGATE_IV`（CI 走 Actions Secret）> 同目录 `.nrapigate_key`（已被
> `.gitignore` 忽略）> **直接抛错**。算法形态与密钥来源已在本报告前面说明，足以复现。

⇒ `x-sign` 不校验、`x-token` 不必需 —— 说明这个网关的**读接口对鉴权是放开的**，
与 09-16 对 `nrzone` 的结论一致。

⚠️ 本机 Python 直连该域名会被沙箱拦 socket（`ChunkedEncodingError: FileNotFoundError`），
但 **curl 通**，所以抓取器用 `subprocess` 驱动 curl；该域名还需 legacy TLS（`OP_LEGACY_SERVER_CONNECT`）。

## 六、可自动化评估

| 项 | 判定 |
|---|---|
| 抓取难度 | ✅ **极低** —— 无凭据、无签名、明文请求体、纯 curl，22 秒全量 |
| 数据性质 | 📖 **只读目录**（备案公示），无签到/抽奖/领取类接口 |
| 可薅的活动 | ❌ **没有** —— 与「动感地带专区」结论一致；这里是查询页，不是活动页 |
| 实际可用价值 | ✅ ① 查「我符合哪些优惠」；② 资费比价；③ **监控资费上下线**（`onlineDay`/`offineDay` 可算出新上架/即将下架）；④ 反查定向优惠门槛，避免被营业厅话术带偏 |
| 落地障碍 | `applicablePeople` 是自然语言门槛，无法机器自动判定用户是否符合；办理渠道多为线下/10086 |

**建议**：不作为"薅羊毛任务"接入挂机助手；可作为一个**资费查询/监控**小工具（想查就查，或每周扫一次差异）。
